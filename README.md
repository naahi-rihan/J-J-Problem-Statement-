# Entropionics — Mall Foot Traffic & Customer Demographics Predictor

> 🏆 Finalist — Microsoft Code Without Barriers Hackathon 2023  
> 📩 Interview invitation received for Internship offer from Johnson & Johnson (Singapore)

## Overview
A machine learning pipeline to identify high foot-traffic malls and 
classify customer demographic attributes (age group, affluence level) 
using data analysis and predictive modeling.

Built with Python, R, and Scala.

## Problem Statement
Retail businesses lack data-driven tools to identify optimal mall 
locations and understand their customer base. Entropionics solves this 
by combining foot traffic data, demographic datasets, and ML 
classification to surface actionable insights.

## How It Works
1. **Data Collection** — Mall directories, public datasets, demographic sources
2. **Feature Engineering** — Location factors, mall attributes, income/age distribution
3. **Model Training** — Random Forest / Gradient Boosting classifier
4. **Prediction** — Mall popularity score + customer demographic profile
5. **Validation** — MSE and accuracy metrics on test split

## Tech Stack
- Python (data processing, ML modeling)
- R (statistical analysis)
- Scala (data pipeline)
- scikit-learn, pandas, numpy
